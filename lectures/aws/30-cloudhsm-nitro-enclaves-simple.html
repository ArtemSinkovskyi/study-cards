Лекція 30: CloudHSM і Nitro Enclaves

Середній рівень: усі правила з повної лекції, але простими словами. Повна: ../30-cloudhsm-nitro-enclaves.md. Теоретична лекція, в AWS не виконувалась. Що не підтверджено документацією, позначено (не звірено).

Головна ідея

CloudHSM це ваш власний апаратний сейф для ключів, Nitro Enclaves це герметична камера для обробки секретних даних. KMS підходить майже завжди, а ці два сервіси для особливих вимог: «ключі лише у нас» і «навіть адмін не повинен бачити дані».

Навіщо це так задумано

KMS ділить інфраструктуру з іншими клієнтами, і ключами керує AWS. Деякі регулятори цього не дозволяють: потрібен пристрій, що належить тільки вам. А деякі дані так чутливі, що їх не мають бачити навіть люди з доступом до сервера. Для цього й створили ці два сервіси.

CloudHSM вміє: створювати й зберігати ключі, шифрувати, підписувати, керувати сертифікатами. Відповідальності більше: ви самі керуєте користувачами HSM.

Для нотаток: Redshift вміє працювати з CloudHSM (не звірено), а CloudHSM підходить для SSE-C, бо ключ тоді лишається у вашому пристрої (не звірено).

Крок 2. Nitro Enclaves

Enclave це маленька віртуальна машина, вирізана з вашого EC2. Вона:

  • не контейнер;
  • не має диска, мережі й SSH;
  • говорить лише зі своїм батьківським EC2 через локальний сокет;
  • недоступна навіть адміністратору батьківського сервера.

Attestation підтверджує, що працює саме дозволений код. У KMS можна написати правило «розшифруй лише для цього enclave». Тому дані бачить лише він.

Для чого: персональні дані, медицина, фінанси; приватні ключі; платіжні картки; обчислення за участі кількох сторін. Окремо за Nitro Enclaves не платять, лише за EC2.

Сценарії: захист приватних ключів, обробка платіжних карток, secure multi-party computation. Це не контейнер.

Що запам'ятати на іспит

  • «Виділений апаратний пристрій, ключі наші» означає CloudHSM.
  • KMS: AWS керує ключами; CloudHSM: ви.
  • Кластер CloudHSM розкидають по зонах для доступності.
  • Enclave: без мережі, диска й SSH, дані невидимі навіть root батька.
  • KMS + attestation: розшифрувати може лише enclave.
