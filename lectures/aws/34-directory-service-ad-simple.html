Лекція 34: Active Directory і AWS Directory Service

Середній рівень: усі правила з повної лекції, але простими словами. Повна: ../34-directory-service-ad.md. Теоретична лекція, в AWS не виконувалась. Факти звірено з документацією Directory Service.

Головна ідея

У компанії вже є Active Directory (AD), де живуть усі працівники. AWS Directory Service дозволяє використати його в AWS. Є три варіанти, і весь іспит у тому, щоб їх не плутати: Managed Microsoft AD (справжній AD в AWS), AD Connector (дверцята до вашого AD), Simple AD (спрощена копія).

Навіщо це так задумано

Компанії з Windows-світу не хочуть заводити людей вдруге в AWS. Тому AWS дає три способи: перенести AD в хмару, лишити AD вдома й підключитися, або взяти дешеву заміну.

Крок 1. Що таке AD

AD це телефонна книга компанії, яка ще й видає перепустки. Вона зберігає об'єкти: користувачів, комп'ютери, принтери, файлові ресурси, групи. Адміністратор створює акаунт один раз і задає права. Об'єкти лежать у деревах, група дерев це ліс. Сервер, що перевіряє паролі, називається domain controller.

Три фрази, за якими впізнаєш відповідь:

  1. «Створити свій AD в AWS і довіряти on-premise» означає Managed Microsoft AD.
  2. «Користувачі лишаються вдома, AWS лише переадресує» означає AD Connector.
  3. «Дешево, без зв'язку з on-premise» означає Simple AD.

Крок 3. Managed Microsoft AD

Це справжній Windows Server AD, яким керує AWS (моніторинг, щоденні знімки, відновлення). Є два видання: Standard (до 5 000 співробітників) і Enterprise (великі компанії). Підтримує MFA, розширення схеми, LDAPS, trust з AD вдома. Єдиний варіант для RDS for SQL Server.

Крок 4. AD Connector

Він нічого не зберігає. Користувач вводить пароль у застосунок AWS, а AD Connector передає його вашому домашньому AD. Користувачами керуєш там, як і раніше. Правила паролів однакові вдома й у хмарі. MFA додається через вашу RADIUS-систему.

Крок 5. Simple AD

Дешева заміна на Samba 4. Вміє базове: користувачі, групи, Kerberos, приєднання EC2. Не вміє MFA, trust, схему, LDAPS. Тому з AD вдома його не з'єднати.

Крок 6. А як же Cognito

Для користувачів вашого застосунку (клієнти, соцмережі) беруть Cognito. Directory Service для корпоративного Windows-світу.

Видання Managed AD: Standard (до 30 000 об'єктів) і Enterprise (до 500 000). Для SaaS-користувачів беріть Cognito, для людей у багатьох акаунтах IAM Identity Center.

Що запам'ятати на іспит

  • Managed Microsoft AD: свій AD в AWS, MFA, trust.
  • AD Connector: лише проксі, користувачі вдома.
  • Simple AD: без MFA і trust, не з'єднується з AD вдома.
  • З трьох варіантів Directory Service з RDS SQL Server працює лише Managed Microsoft AD.
  • Користувачі застосунку (SaaS, соцмережі): Cognito.
