Lecture 1: what the exam is and where to start

Simplified version. The full lecture exists in Ukrainian only.

What the exam is

Claude Certified Architect, Foundations (CCA-F) is an Anthropic certification. These figures come from third-party sites; I did not find an official guide, so check the official Anthropic page before you book.

What Value
Questions 60 multiple choice
Time 120 minutes
Passing score 720 of 1000
Price 99 or 125 dollars (sources disagree)

Why it is designed this way

The certification does not test whether you memorised the API. It tests whether you can design reliable systems around the model. So the questions are about decisions and traps.

Lectures 9-13 follow the exam course, one per domain. They hold the decisions and traps the exam tests most often.

Agentic architecture is the hardest and the most important topic, so start there.

One sentence per topic

  • Agentic architecture: the model asks for tools and your code runs them (the loop).
  • Tools and MCP: how to describe tools and connect external systems.
  • Prompts: how to write instructions and check that they work.
  • Claude Code: what only advises (CLAUDE.md) and what guarantees (permissions, hooks).
  • Context: what fills the window, how to shrink it and how to save with caching.

How to study

  1. Read lectures 2-8, then 9-13 (the course domains). Each takes 15-20 minutes.
  2. After each lecture answer the questions at the end.
  3. Spend 5-10 minutes a day on the cards. Do not learn all 156 at once, take one group at a time.
  4. At the end take the tests, including the five domain tests. Put your mistakes back into the cards.

Official documentation (where to read more)

  • Tools: Tool use overview, How tool use works, Define tools
  • MCP: MCP connector, MCP in Claude Code
  • Prompts: Prompting best practices, Evaluations
  • Context: Context windows, Prompt caching, Compaction
  • Claude Code: Memory, Hooks, Permissions, Skills, Subagents

Glossary

Term What it is
Agentic architecture the model calls tools in a loop until it is done
Tool a function the model can ask you to run
MCP an open protocol for connecting external tools
Context everything the model sees in a request: prompt, history, results
Token a unit of text; input, output and price are counted in tokens
Prompt the instructions and data you give the model

What to remember

  1. The exam: 60 questions, 120 minutes, 720 of 1000.
  2. Five topics: agentic architecture, tools and MCP, prompts, Claude Code, context.
  3. These figures come from third-party sites; check the official page before you book.
