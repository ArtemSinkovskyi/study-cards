Лекція 1: що за іспит і з чого починати

Спрощена версія. Повна: ../1-claude-architect-reading-map.md.

Що це за іспит

Claude Certified Architect, Foundations (CCA-F) це сертифікація Anthropic. Дані з сторонніх сайтів, офіційного посібника я не знайшов, тож перевірте на офіційній сторінці Anthropic перед записом.

Що Значення
Питань 60 тестових
Часу 120 хвилин
Прохідний бал 720 з 1000
Вартість 99 або 125 доларів (джерела розходяться)

П'ять тем іспиту

Ваги з сторонньої сторінки, вагу п'ятої теми не підтверджено.

Тема Вага Лекції
Агентна архітектура 27% 2
Claude Code 20% 5, 8
Промпти 20% 4
Інструменти й MCP 18% 3
Контекст не підтверджено 6, 7

Агентна архітектура найважча й найважливіша, з неї й починайте.

Одна фраза про кожну тему

  • Агентна архітектура: як модель просить інструменти, а ваш код виконує (цикл).
  • Інструменти й MCP: як описувати інструменти й підключати зовнішні системи.
  • Промпти: як писати інструкції й перевіряти, що вони працюють.
  • Claude Code: що лише радить (CLAUDE.md), а що гарантує (дозволи, hooks).
  • Контекст: що займає вікно, як зменшувати його й як економити на кеші.

Як вчити

  1. Читайте лекції в порядку 2, 3, 4, 5, 6, 7, 8. Кожна займає 15-20 хвилин.
  2. Після кожної лекції відповідайте на питання в кінці.
  3. Щодня 5-10 хвилин на картки (cards.html). Не вчіть усі 103 відразу, беріть по одній групі.
  4. Наприкінці проходьте тести (tests.html). Помилки повертайте в картки.

Офіційна документація (де читати докладніше)

  • Інструменти: Tool use overview, How tool use works, Define tools
  • MCP: MCP connector, MCP у Claude Code
  • Промпти: Prompting best practices, Evaluations
  • Контекст: Context windows, Prompt caching, Compaction
  • Claude Code: Memory, Hooks, Permissions, Skills, Subagents

Що запам'ятати

  1. Іспит: 60 питань, 120 хвилин, 720 з 1000.
  2. П'ять тем: агентна архітектура, інструменти й MCP, промпти, Claude Code, контекст.
  3. Це дані зі сторонніх сайтів, офіційну сторінку перевірте перед записом.
