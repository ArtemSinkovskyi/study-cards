1. The big picture

The course has five parts: What we mean by AI (what is generative AI), How AI is trained (pretraining, fine-tuning), Properties of AI (four of them), Putting it all together (what happens when properties collide) and Next steps (using this safely, effectively, ethically).

  • Generative AI produces new content. Other AI sorts, ranks and classifies existing content (spam filter, video recommendations).
  • AI is not uniformly capable and not uniformly unreliable. It is strong and weak along four predictable axes.
  • Each axis is a continuum: from capability zone to limitation zone. The same mechanism gives you both the capability and the limitation.
  • Calibrated trust means locating your task on the continuum, not trusting or distrusting everything.

Remember: four properties = how the machine behaves. 4D = what you do about it.

2. How AI gets its "character": training

таблицю можна гортати вбік →
Stage What happens Result
Pretraining Trained on a massive amount of text to learn patterns and predict the next token A document completer, not yet a helpful assistant
Fine-tuning Refined to be broadly safe, ethical and helpful, to follow instructions An assistant with a disposition

Fine-tuning leaves fingerprints on everything: the model is polite and helpful, but also shows traits such as sycophancy (agrees too easily), verbosity, overcaution and loose confidence calibration. Reward during training shapes these traits.

3. The four properties

таблицю можна гортати вбік →
Property Question Capability zone Limitation zone
Next Token Prediction Where do answers come from? Well-worn paths: summarize, reformat, explain common concepts, draft in a familiar style Novel territory, sparse patterns, "true vs. sounds true"
Knowledge What does AI actually know? Frequent, recent-in-training, consistent: mainstream science, popular programming languages Rare, post-cutoff, niche, local or contested topics
Working Memory What is it paying attention to now? Material fits the window, session is current, you supply context Very long documents or chats, expecting memory across sessions (the cliff)
Steerability How much am I in control? Short, concrete, verifiable instructions ("as a table", "under 100 words") Long reasoning chains, abstract asks, native numerical precision

3.1 Next Token Prediction

  • The model writes word by word (token by token) based on what tends to follow what. It does not look an answer up in a database.
  • Picking the next token from a probability distribution is called sampling. The same request can give different answers (temperature, top-k and similar knobs control sampling).
  • Old idea, new scale: a Markov chain (1906) is a frequency table of word pairs; an LLM does a forward pass through billions of parameters, but the output is still a probability distribution over the next token.
  • Fabrication concentrates in specifics: names, dates, statistics, citations, URLs, quotes. The more precise the claim, the more it needs checking.
  • Product features that push the limit outward: citations, uncertainty signaling, constrained generation, generator-verifier loops.
  • 4D link: this is the foundation of Discernment. Knowing the text was generated tells you what scrutiny to apply.

3.2 Knowledge

  • Knowledge comes only from training data and is frozen at the knowledge cutoff. Without tools there is no real-time browsing.
  • The useful question is not "does it know this?" but "how well represented was this in what it read?"
  • Characteristic failures: staleness, uneven coverage, inherited bias (what counts as "default" or "normal"), source amnesia (cannot say where it learned something).
  • Fixes: web search, retrieval / RAG, MCP, tool use: give the model information it never saw.
  • Embeddings (how retrieval finds meaning): an embedding model turns any text into a fixed-length list of numbers (for example 1,024). Similar meaning means nearby points. Closeness is measured by cosine similarity (direction of vectors): -1 opposite, 0 unrelated, 1 identical. The axes are emergent: nobody can say what dimension 847 means.
  • 4D link: uneven knowledge is core to Delegation: when to hand off, when to bring context yourself.

3.3 Working Memory

  • Everything the model attends to lives in a fixed-size context window. It cannot attend to what is outside it.
  • It is a cliff, not a gradient: it works until it does not, and silent truncation may give no warning.
  • The model does not learn from your corrections: a new chat starts from zero. It only reacts to what is in context.
  • Lost in the middle: like the human serial position effect (primacy + recency), models recall the start and end best; a 2023 Stanford study saw accuracy drop by more than 30% for facts buried in the middle.
  • Practice: put the key instruction first, repeat it at the end, curate context (more context is not better), start fresh when needed.
  • Features that move the cliff: memory, compaction, projects, larger windows, multi-agent workflows.
  • 4D link: Working Memory is what Description acts on.

3.4 Steerability

  • The model follows instructions the same way it does everything else: by continuing a pattern (fine-tuning taught it instruction-following). So there is always a gap between intent and result.
  • Characteristic failures: reasoning drift (small early errors compound), letter over spirit (instruction honored, intent missed), brittle arithmetic (native math is unreliable).
  • Fixes: restate the goal, not only the format ("Make this shorter. My goal is to keep the executive's attention"). Repeating an instruction louder does not close the gap. Insert checkpoints. Use system prompts, code execution, visible reasoning, structured outputs.
  • 4D link: Steerability makes Description powerful and bounds it.

4. When properties collide

Most real failures are two properties at once:

таблицю можна гортати вбік →
Failure Properties Targeted fix
Hallucinated citation or fact Next Token Prediction + Knowledge Verify specifics, use search or retrieval, citations
Long-conversation drift Working Memory + Steerability Re-supply context, restate the goal, start fresh
Confidently wrong math Next Token Prediction + Steerability (the course names this failure; the pair is my reading) Offload to code execution
Agreeable bad premise (sycophancy) Steerability + Knowledge (my reading; the course does not name the pair) Invite pushback, ask for the counter-argument

Naming the two properties points you straight to the fix. That is Discernment in action.

5. The 4D Framework

таблицю можна гортати вбік →
D Meaning Driven by
Delegation What to hand to AI and what needs human control Knowledge
Description How to describe the task: goal, context, constraints, format Working Memory, Steerability
Discernment How to judge what comes back, spotting errors and hallucinations Next Token Prediction
Diligence How to verify and use AI responsibly the course does not tie it to one property

The 4Ds are what you do; the properties are what you are responding to when you do them.

Calibrated trust by task: general explanations, trust more; dates, quotes, links, verify; architecture decisions, validate deeply; critical security decisions, independent review is mandatory. Models will keep changing, but the shape of these properties stays useful.
