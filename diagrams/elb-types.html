🖼 ELB: ALB, NLB, GWLB, CLB, SNI

Чотири балансувальники
ALB: Application
  • L7
  • HTTP, HTTPS, WebSocket
  • правила listener за пріоритетом
  • мікросервіси, контейнери
NLB: Network
  • L4
  • TCP, TLS, UDP
  • статичні IP, Elastic IP
  • мільйони запитів на секунду
GWLB: Gateway
  • L3
  • IP, GENEVE (порт 6081)
  • фаєрволи, IDS/IPS
CLB: Classic
  • L4 і L7
  • застарілий
  • previous generation
